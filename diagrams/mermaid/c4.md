# c4

Ajánlott architektúra a Bandhub rendszerhez (indoklás: [`../../docs/Rendszerdokumentacio.md`](../../docs/Rendszerdokumentacio.md#sec-4-1) 4.1–4.3). A [C4 modell](https://c4model.com) 3 fő absztrakciós szintje (Context → Container → Component) mellett egy kiegészítő Deployment diagram is tartozik hozzá.

> **Kanonikus forrás:** [`../c4.puml`](../c4.puml) — a hivatalos [C4-PlantUML](https://github.com/plantuml-stdlib/C4-PlantUML) sablonkönyvtárral (PlantUML standard library, `<C4/...>` include) készült, iparági szabvány szerinti PlantUML forrás, mind a 4 diagrammal. Az alábbi Mermaid fájlok ugyanezt a tartalmat, ugyanazokkal az elem-/kapcsolatnevekkel tartalmazzák, kizárólag azért, mert a GitHub és a legtöbb Markdown-előnéző natívan csak a Mermaid-et rendereli inline — a PlantUML-hez külön renderelő (pl. a PlantUML VSCode-bővítmény vagy a `plantuml` CLI) kell. **A két forrás tartalmilag azonos; eltérés esetén a `c4.puml` az irányadó.**

**A modell 3 fő szintje (mindegyik ugyanazt a rendszert nagyítja bele fokozatosan):**
- [Context.md](Context.md) — C4 szint 1: rendszerkontextus (ki használja, milyen külső rendszerrel érintkezik)
- [Container.md](Container.md) — C4 szint 2: konténerek (Web/Asztali/Mobil kliens, reverse proxy, backend, adatbázis, objektumtár)
- [Component.md](Component.md) — C4 szint 3: a Backend API konténer belső moduljai

**Kiegészítő diagram:**
- [Deployment.md](Deployment.md) — a Container-diagram konténereinek fizikai elhelyezése éles környezetben (Docker Compose stack)
